Clear Folder

Clear Folder is a Windows utility that helps keep frequently used folders clean by automatically identifying old files that can be removed.

The application maintains a personal list of folders to monitor. Folder settings are stored in the Windows Registry and automatically restored every time the application starts on the same machine.

For each monitored folder, Clear Folder displays:

- Number of files eligible for deletion

- Total size of those files

- Estimated disk space that can be reclaimed

Users can choose to either:

- Move old files to the Recycle Bin

- Permanently delete old files

The application can also display Recycle Bin usage and empty the Recycle Bin directly.

Features

- Monitor multiple folders

- Persist folder configuration between sessions

- Add and remove folders at any time

- Configure a file age threshold in days

- View file count and reclaimable disk space before deletion

- Select individual folders for cleanup

- Open monitored folders directly from the application

- Move files to the Recycle Bin

- Permanently delete files

- Empty the Windows Recycle Bin

How It Works

- Add one or more folders to the monitored list.

- Choose how many days old a file must be before it becomes eligible for deletion.

- Review the number and size of files that match the criteria.

- Select the folders you want to clean.

- Execute the cleanup operation.

- Only files older than the configured threshold are removed.


Folder Management

- Folders added to the application are automatically saved in the Windows Registry.

- The next time Clear Folder is started on the same computer, the configured folders will already be available and rescanned automatically.

- Removing a folder from the monitored list does not delete the folder or any files inside it. It only removes the folder from the application's configuration.

Deletion Modes

- Send to Recycle Bin: Files are moved to the Windows Recycle Bin and can be restored later if needed.

- Delete Permanently: Files are removed immediately and cannot be restored through the Recycle Bin. Use this option with caution.
